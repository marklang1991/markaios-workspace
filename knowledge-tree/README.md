# Mark Knowledge Tree

This directory mirrors the structure of the Notion knowledge base without copying private page content.

## Entry points

- [Architecture and maintenance rules](ARCHITECTURE.md)
- [Notion page map](NOTION-MAP.md)
- [Reusable project template](templates/project.md)

## Operating model

1. Capture unclassified material in `98 Inbox`.
2. Run active work from `12 Project Hub`.
3. Distill reusable conclusions into domains `01` through `11`.
4. Move completed or superseded material to `99 Archive`.
5. Keep personal data and confidential project details in Notion; sync only structure, templates, and sanitized documentation to GitHub.

## Sync policy

- Notion is the source of truth for private knowledge and project context.
- GitHub is the source of truth for versioned architecture, templates, automation, and public-safe documentation.
- Links may point to private Notion pages, but their contents must not be duplicated here unless explicitly reviewed for disclosure.
